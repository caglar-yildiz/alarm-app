Privacy Policy

Application: BENG Alarm

Last updated: November 13, 2026

1. Introduction

BENG Alarm is an Android alarm application designed to help users schedule and manage alarms. We respect user privacy and aim to be transparent about how the application operates.

2. Advertising and Accounts

The application does not display advertisements and does not require users to create an account or sign in.

3. Application Permissions

The application may request Android permissions necessary for alarm functionality, including:

  • Scheduling alarms and reminders.
  • Displaying notifications.
  • Running alarm-related background operations.
  • Waking the device when an alarm is triggered.
  • Restoring scheduled alarms after device restart.

These permissions are used to support the application's alarm functionality.

4. Data Storage and Processing

The application may store alarm settings and preferences locally on the user's device. Any additional data processing or third-party services must be disclosed in this policy if applicable.

5. Third-Party Services

The application does not currently integrate an advertising service. Any third-party services that process user information will be identified in future policy updates.

6. Data Security

We aim to protect information handled by the application through appropriate technical measures.

7. Children's Privacy

The application is a general-purpose alarm utility and is not specifically designed for children.

8. Changes to This Policy

This privacy policy may be updated when application functionality or data practices change. Updates will be published on this page.

9. Contact

For privacy-related questions, please contact the application developer using the contact information provided in the Google Play Store listing.
